# QSynEdit HTML / RTF 导出优化结果

测量环境、样本和命令见 `qsynedit-exporter-baseline.md`。下表为最终实现的同场景 Release 结果。

| 格式 | 行数 | 基线字节数 | 最终字节数 | 基线 ms | 最终 ms |
|---|---:|---:|---:|---:|---:|
| HTML | 10,000 | 618,361 | 308,420 | 22.25 | 20.25 |
| HTML | 100,000 | 6,378,361 | 3,278,420 | 222 | 209 |
| RTF | 10,000 | 358,016 | 358,006 | 21.5 | 20 |
| RTF | 100,000 | 3,778,016 | 3,778,006 | 224 | 209 |

- HTML 尺寸约减少 50.1%（10,000 行）和 48.6%（100,000 行），主要来自普通空格和实际换行替代逐空格实体及 `<br>`。
- RTF 的纯 ASCII token 直接输出，避免 Unicode 兼容处理引入额外分配；最终耗时不高于本组基线。
- RTF 重复导出的颜色表和输出尺寸保持稳定，不再因复用 exporter 而变化。
- 单次大样本耗时仍受调度影响，结论以尺寸和数量级为主，不把少量时间差解释为精确加速比。
- 不包含磁盘、剪贴板和阅读器渲染成本。

## 逐行语义高亮统一结果

日期：2026-11-23。统一 Exporter 与 Painter 的逐行表达式提取、求值和 statement 颜色映射后，使用同一 `miniaudio.h` 样本复测；最终结果为 5 次平均，基线为 3 次平均。

| 格式 | mIdCache | 基线 ms | 最终 ms | 降幅 |
|---|---|---:|---:|---:|
| HTML | 冷 | 7,058.055 | 3,210.931 | 54.5% |
| RTF | 冷 | 9,061.742 | 3,487.837 | 61.5% |
| HTML | 热 | 9,269.845 | 3,533.706 | 61.9% |
| RTF | 热 | 9,123.051 | 3,459.450 | 62.1% |

- 四种场景的输出字节数均与基线一致：HTML 4,309,778，RTF 4,712,466。
- 新实现的热缓存仍需要整行分词和表达式扫描，因此不保证比冷缓存更快；主要收益来自消除逐 identifier 的独立表达式提取与求值。
- 无 Parser 的 10,000/100,000 行通用导出结果分别为 HTML 24/246 ms、RTF 22/227 ms，输出字节数不变。相比上一轮 20.25/209 ms 和 20/209 ms，整行 token 列表带来一定通用开销；列表已跨行复用并预留容量，避免逐行分配和反复扩容。
- 语义导出收益显著高于通用序列化开销。通用大样本为单次 QBENCHMARK，少量波动不作为精确加速比。
