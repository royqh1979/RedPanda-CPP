# 试题集期望输出比对优化结果

## 实现与测量

在 `problemset-validator-baseline.md` 的相同环境和样本上测量。实现使用按行 `QStringView` 游标，不再构造完整行列表或逐行字符串；忽略所有空白时直接逐字符比较。

下表为三轮 Release profile 的中位数，单位毫秒。类型定义和运行命令见基线文档。

## 审核与限制

- 大文件正确性、差异位置、双方行数、外部文件优先级和 UTF-8 错误均有测试覆盖。
- 三轮中仍有少量单次调度波动，例如 100,000 行精确比对和 500,000 行空白比对的个别样本；中位数不改变数量级结论。
- 未直接测量内存占用；可以确认实现消除了完整行列表和逐行字符串分配，但不能据此给出具体内存下降数字。
- 结果不包含进程输出采集、MainWindow 展示或后台线程调度成本。验证目前仍在 UI 线程执行。
